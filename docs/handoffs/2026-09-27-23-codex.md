## 2. Corrective implementation

`Workspace.claim_task` now gates only on latest, non-superseded handoffs. An
acknowledged correction therefore permits a claim even when its preserved
predecessor was never acknowledged.

`Workspace.publish_handoff` now rejects a supersession unless the predecessor
has the same run, task, and recipient.

`Workspace.acknowledge_handoff` validates the supplied SHA-256, re-reads and
hashes the current regular handoff file, and fails closed for a missing,
symbolic-link, oversized, unreadable, or changed file. Repeating the same exact
acknowledgment returns the original timestamp and records no duplicate event.

- returns bounded errors for oversized lines, invalid UTF-8, malformed JSON,
  invalid envelopes, invalid calls, workspace failures, database failures,
  and expected I/O failures;
- continues serving later requests after a bad request;
- validates JSON-RPC version, method, and identifier type;
- wraps `tools/call` output in matching MCP `content` and
  `structuredContent` fields;
- bounds the complete serialized response, including the identifier and
  JSON-RPC envelope, to 64 KiB; and
