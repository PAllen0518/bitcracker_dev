### Findings, most severe first

1. **CRITICAL, CONFIRMED, migration can proceed without a legacy backup.**
   `BitCracker/btcrecover-master/multibit_cuda_threads.cu:1174-1178` ignores
   the return from `copy_file_durable`. Failure scenario: the `.legacy` and
   `.prev` destinations cannot be replaced, typed `REBIND` still starts the
   search, and a later successful v1 rename replaces the only 1064-byte legacy
   save. The mandatory no-clobber guarantee is not enforced.
2. **HIGH, CONFIRMED, backup copies can falsely report durability.**
   `BitCracker/btcrecover-master/save_format.hpp:355-373` ignores `fflush` and
   `_commit` return values and renames without `MOVEFILE_WRITE_THROUGH`.
   Failure scenario: a flush or commit fails, the function reports success,
   and the program overwrites the primary while the `.legacy` backup is not
   durable. The same helper is used for `.prev`.
3. **HIGH, CONFIRMED, `.prev` retention failure is ignored.**
   `BitCracker/btcrecover-master/save_format.hpp:397-401` advances the primary
   save even when `copy_file_durable` fails. Failure scenario: the old primary
   is atomically replaced with no retained prior generation, contrary to the
   approved every-save retention decision. Existing tests do not inject this
   failure.
4. **HIGH, CONFIRMED, oversized v1 saves are accepted.**
   `BitCracker/btcrecover-master/save_format.hpp:420-428` reads one record and
   ignores trailing bytes, while `save_format.hpp:445-447` classifies any
   magic-prefixed file at least one record long as v1. Failure scenario:
   appended corruption or an unintended extra record is silently accepted.
   This contradicts the gauntlet's oversized-file refusal requirement and the
   evidence statement that only the exact v1 size is recognized.
5. **MEDIUM, CONFIRMED, the legacy offset proof is not independent.**

   documented offsets but uses zero `perm_idx` and `typo_idx`. No
   `static_assert` pins `sizeof` or `offsetof`, and integer decoding assumes
   the native little-endian ABI. Failure scenario: a layout or offset error can
   pass the self-generated host fixture while misreading the real nonzero
   resume indices.
6. **MEDIUM, CONFIRMED, end-to-end binding coverage is incomplete.** All nine
